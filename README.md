# 即梦数字人音频智能裁切工具

为数字人视频制作提供音频智能分段，每段≤36秒，自动基于歌词时间轴切分。

## 功能特性

- 🎵 支持 MP3/WAV/M4A 音频格式
- 📝 LRC 歌词解析
- ✂️ 智能分段（每段≤36秒）
- 🔇 静音检测和去除
- 📦 批量导出

## 技术栈

- Next.js 14
- FFmpeg.wasm
- TypeScript
- Tailwind CSS

## 快速开始

```bash
# 安装依赖
pnpm install

# 开发模式
pnpm dev

# 构建
pnpm build
```

## 使用说明

1. 上传音频文件
2. 粘贴 LRC 格式歌词
3. 点击"智能分段"
4. 预览分段结果
5. 导出全部片段

## LRC 格式示例

```
[00:12.00]第一句歌词
[00:17.20]第二句歌词
[00:23.00]第三句歌词
```
